Git/GitHub Anomalies
====================

A collection of experiments exploring limits, edge cases, unusual behavior,
and anomalies in Git and GitHub.

Experiments
===========

The repository will contain experiments involving:

* `Extremely large commit histories <https://github.com/gitmodules/committed>`__
* Maximum-length repository names
* Maximum-length branch names
* Unusually long commit titles
* Unusually large commit messages
* Unusual tags and references
* Empty commits
* Large Git objects
* Unusual filenames and paths
* Git metadata edge cases
* GitHub-specific naming and UI behavior

Purpose
=======

This repository is used to determine what Git and GitHub accept, reject, or
handle unexpectedly.
